# EtharaChats

## Overview

You are a professional experienced web developer. You have to build a full-stack web app named **"EtharaChats"**. This web app includes a real-time group chat where users can join by entering their identity details like name and gender before entering the chat room. The web app should be fully functional, responsive, and production ready.

## Frontend
- The website UI should be responsive.
- The UI theme should be orange, pink, and black.
- The website contains a landing page and, before entering the chat room, a popup should be displayed where users can enter their name and gender.
- Also show online users list with gender.
- The UI should be smooth and real-time.
- The message screen should include the sender's name, gender, and the timestamp.

## Backend 
- No complex authentication is required.
- Use HTML, CSS, JavaScript, a basic HTTP server, and Socket.io as the tech stack.
- Create all backend features and events.
- The web app should include proper error handling.
- Provide complete working source code for frontend and backend with all features and functionalities.
